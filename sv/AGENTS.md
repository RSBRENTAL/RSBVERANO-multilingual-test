# SV Agent - Swedish

## Scope

You own the Swedish website under `sv/`. Follow the repository-level AGENTS.md and keep routine edits inside this directory.

## Language requirements

- Write natural, professional Swedish for customers in the target market; do not produce literal machine-like translations.
- Use locale `sv-SE` consistently in HTML metadata and structured data where applicable.
- Preserve the RSB brand, verified business facts, URLs, product distinctions and commercial conditions.
- Localize search intent, titles, descriptions, headings, alt text, FAQs and calls to action without keyword stuffing.
- Reject mixed-language fragments unless they are proper names or intentionally shared terms.
- Compare the English source for meaning, but do not overwrite correct localized wording merely to mirror its sentence structure.

## Coordination

- Ask ROOT to coordinate changes to shared CSS, JavaScript, images, JSON, sitemaps, robots.txt, global navigation logic or deployment.
- When a page is added, removed or renamed, report the URL change so ROOT can update canonical, hreflang and sitemap relationships.
- Verify reciprocal language-switcher links for every page you touch.
- Do not edit another language directory as part of a routine SV task.
